# Git Ignore Guide for Tailor Billing Manager

This document explains what files should and should NOT be committed to Git for the `tailor-billing-manager` folder.

## ✅ Files to COMMIT (Source Code & Documentation)

These files should be committed to Git:

- **Source Code:**
  - `main.py` - Main GUI application
  - `config.py` - Configuration file
  - `service_manager.py` - Service management functions
  - `git_sync.py` - Git synchronization functions
  - `__init__.py` - Package initializer
  - `build_exe.py` - Build script for creating executable

- **Documentation:**
  - `README.md` - Main documentation
  - `QUICK_START.md` - Quick start guide
  - `ADMIN_REQUIREMENTS.md` - Admin privileges documentation
  - `GIT_BRANCH_INFO.md` - Git branch information
  - `NETWORK_TROUBLESHOOTING.md` - Network troubleshooting guide
  - `BUILD_INSTRUCTIONS.md` - Build instructions
  - `GIT_IGNORE_GUIDE.md` - This file

- **Configuration & Scripts:**
  - `requirements.txt` - Python dependencies
  - `build.bat` - Build batch script
  - `run.bat` - Run script
  - `BUILD.bat` - Alternative build script

## ❌ Files to IGNORE (Build Artifacts)

These files are automatically ignored by `.gitignore`:

- **Build Artifacts:**
  - `build/` - PyInstaller build cache folder
  - `dist/` - Contains the compiled executable (`TailorBillingManager.exe`)
  - `*.spec` - PyInstaller spec files (generated automatically)

- **Python Cache:**
  - `__pycache__/` - Python bytecode cache
  - `*.pyc` - Compiled Python files

## Why Ignore These Files?

1. **`build/` folder:**
   - Contains temporary build files generated by PyInstaller
   - Can be regenerated anytime by running `build.bat`
   - Large in size and not needed in repository

2. **`dist/` folder:**
   - Contains the compiled executable (`TailorBillingManager.exe`)
   - Executables are large binary files (can be 10-50MB+)
   - Should be built on each system, not committed
   - Different executables needed for different operating systems

3. **`*.spec` files:**
   - PyInstaller configuration files
   - Auto-generated during build process
   - Can be regenerated if needed

## Current .gitignore Rules

The following rules are already in the root `.gitignore`:

```gitignore
# Tailor Billing Manager - Build artifacts
tailor-billing-manager/build/
tailor-billing-manager/dist/
tailor-billing-manager/*.spec
tailor-billing-manager/__pycache__/
```

## How to Build the Executable

If someone clones the repository, they can build the executable by:

1. Navigate to `tailor-billing-manager` folder
2. Run `build.bat` (or `python build_exe.py`)
3. The executable will be created in `dist/TailorBillingManager.exe`

## Checking What Will Be Committed

Before committing, you can check what files will be included:

```bash
git status
```

Or check what would be ignored:

```bash
git check-ignore -v tailor-billing-manager/*
```

## Summary

**Commit:** Source code, documentation, configuration files, and scripts  
**Ignore:** Build artifacts, executables, cache files, and generated files

This keeps the repository clean and allows each developer to build their own executable on their system.
